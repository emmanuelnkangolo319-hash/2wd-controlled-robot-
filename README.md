# 2wd-controlled-robot-
This is a 2 wheeled robot that is built for emergency, but for now it basic funcions are to move and send camera feed.

This build is probably going to take alot out of me, but i think it is possible.
Im doing this because after watching countless videos of firefighters talking to traumatized citizen, they cant get real numbers, like how many people are still inside, in which rooms, if they had these numbers, it would decrease the risk in those operations

Build plan:
this section will cover how to build this, i will show a video soon(please go to 3d model/Assembly 1 for more info).
1. Sand the wheels down, both the insides and outsides
2. Brush on one thin layer of epoxy resin on the outside of the wheels
3. Place your carbon fiber sheets on the outside of the wheels where you applied the epoxy
4. Add one more layer of epoxy on top and check the kit to see how long it should cure
5. After letting it cure. in the insides of the wheels, add some glue(super glue/hot glue). Then carfully put the foam inside, trying to go from the center to the edges of the wheel
6. last part will be showing you how to put the electronics in, and the foam for shock absorption
